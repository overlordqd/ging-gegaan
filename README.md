# Ging Gegaan

A small study app for Dutch verbs: 92 irregular and 60 regular verbs, with their meaning, imperfectum (singular and plural) and perfectum.

- **Kaarten** (flashcards): flip each card to see the forms, then mark it as known or still to practise. Filter by irregular, regular or vowel pattern.
- **Quiz**: type the imperfectum and perfectum. Optionally pick the meaning too. Choose irregular, regular or mixed.
- **Lijst** (list): a searchable reference table.

It's a single `index.html` with no build step. Open it in a browser, or serve it with GitHub Pages. Progress is saved in the browser's localStorage. Icons are from [Lucide](https://lucide.dev), loaded from unpkg.
